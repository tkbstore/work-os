Can this repository leave your machine?

work-os release gate answers one permission question before you share or open-source a git repository. It is fail-closed: a check that did not run is reported as unmeasured, never as passed. Python standard library only, no install beyond one script.

How it decides

Stage 1 — internal

Blocks only what is irreversible once shared: committed secrets (judged by the value and whether its host is reachable, not by variable names), tracked real .env files, home-directory paths, a missing .gitignore.

Stage 2 — public

Adds what a stranger needs: license, an entry point in the README, tests that actually run, robustness, and a history lane that scans every published blob and commit message, not just the working tree.

Cumulative

One ladder, cut in two. A failed stage stops the measurement; nothing above it is reported as reached. warn never blocks; a block check that was not executed keeps the stage open.

Measured against {{CORPUS_N}} public repositories

The thresholds are not taste. The same gate (release_gate.evaluate(), unchanged) is run against a declared corpus, and the frozen result is committed. Published repositories are ground truth for "may be published", so a stage-1 stop on them is a false-positive candidate that we inspect by hand. Frozen on {{FROZEN_ON}}; {{EXCLUDED_N}} repositories could not be measured and are listed with the reason in the result file.

Stage 2 is not a popularity score. On this corpus the gate does not separate widely adopted projects from rarely adopted ones, and we say so in calibration/README.md. Commands from other people's repositories are never executed during calibration, so execution checks are unmeasured there.

The rules the gate and the framework rely on are stated as {{THEOREM_N}} theorems in formal/ and checked by lake build. The specification is not a proof that the Python implementation follows it; it is a precise statement that can be wrong in the open. What it does not do

  • It cannot find a leak of a shape nobody has described. A clean stage 1 means "none of the declared shapes", not "safe".
  • Removing a file does not remove it from history or from a host that already served it. The history lane tells you that; it cannot undo it.
  • Customer and private names are your organisation's data. They live in your own configuration, never in this repository.
